# 📞 Customer Churn Prediction Analysis

## 📖 Project Overview

This project focuses on predicting customer churn using Machine Learning techniques. Customer churn refers to customers who stop using a company's services. Identifying potential churn customers helps businesses improve customer retention and reduce revenue loss.

The project includes data cleaning, exploratory data analysis, feature engineering, machine learning model development, and performance evaluation.

## 📊 Dataset

**Dataset:** `customer_churn_dataset_1000_rows.csv`

The dataset contains customer demographic, subscription, and usage related information used to predict customer churn.

### 📌 Features

* 👤 Age
* ⏳ Tenure
* 📱 Usage Frequency
* ⏰ Support Calls
* 💰 Payment Delay
* 💵 Total Spend
* 📦 Subscription Type
* 🌍 Contract Length
* 😊 Satisfaction Score
* 🚪 Churn
